TuitionMate — HTML5 & CSS3 Project

Files
- index.html: Home page
- login.html: Login page
- style.css: Shared responsive styles

How to run
1. Extract the project folder.
2. Open index.html in a web browser, or open the folder in VS Code and use Live Server.
3. Click Login or Sign Up to open login.html.

Technology
- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Google Fonts (Inter) and Font Awesome icons are loaded from CDNs, so those decorative assets require an internet connection.

Important note
This is a front-end coursework demonstration. The login form does not authenticate users, Google login is a visual UI link, and password reset/sign-up links open an email draft. Real authentication requires a backend and should not be implemented with HTML/CSS alone.
